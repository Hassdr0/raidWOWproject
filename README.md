# Sistema de Cadastro de Players para Raids

Este projeto foi desenvolvido para fins comunitarios de uso na comunidade do wow classic br, do jogo World of Warcraft. A ideia inicial é de integrar a API do warcraftlogs e ter um registro de dados dos player brasileiros do servidor Faerlina e afins, e ter uma "comparação" saudável a comunidade.
---

## Tecnologias Utilizadas
- Java  
- Spring Boot  
- PostgreSQL  
- Autenticação via JWT  
- Documentação via Swagger  
- Deploy previsto na AWS  

---

## Objetivo do Projeto
O foco é aplicar e reforçar:
- Criação de APIs RESTful com Spring Boot  
- Integração com banco de dados relacional PostgreSQL  
- Implementação de autenticação com JWT  
- Uso de Swagger para documentação da API  
- Noções de deploy em nuvem (AWS)  

---

## Como Executar
1. Clone este repositório.  
2. Configure o banco PostgreSQL (crie banco, usuário, etc).  
3. Ajuste as credenciais de conexão no arquivo de configuração (ex.: `application.properties`).  
4. Execute a aplicação localmente (por exemplo via IDE ou comando Maven).  
5. Acesse a documentação da API via Swagger (normalmente em `http://localhost:8080/swagger-ui.html`).
